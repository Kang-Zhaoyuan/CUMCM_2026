# 全国大学生数学建模竞赛 LaTeX 论文结构模板

本模板依据压缩包中历年优秀论文的高频结构整理，只抽取“文章组织方式”，不复用具体内容。

## 最稳定的主线

1. 摘要与关键词
2. 问题重述
3. 问题分析（逐问分析 + 可选总体思路图）
4. 模型假设
5. 符号说明
6. 数据预处理与基础分析（数据型赛题保留；纯机理题可删除）
7. 模型的建立与求解（逐问展开）
8. 模型评价与改进/推广
9. 参考文献
10. 附录（支撑材料清单、补充结果、源代码）

## 单个问题内部推荐顺序

模型准备/承接关系 → 模型建立 → 求解算法 → 结果分析 → 模型检验/敏感性分析。

## 两种常见正文组织方式

- **集中式**：设一个“模型的建立与求解”大节，下面依次写问题一、二、三、四。本模板默认采用这种方式。
- **分节式**：把“问题一的模型建立与求解”“问题二的模型建立与求解”等分别设为一级标题。问题较多、每问篇幅较长时可采用。

## 使用说明

- 在 Overleaf 中上传整个文件夹（或上传压缩包并解压），主文件选择 `main.tex`。
- 编译器建议使用 XeLaTeX。
- 不设置目录。
- 若赛题只有 3 问或有 5 问，直接删除/复制对应小节即可。
- 若赛题不依赖数据，可删除 `sections/05_data_processing.tex` 以及 `main.tex` 中对应的 `\input`。
