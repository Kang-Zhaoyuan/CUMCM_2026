# 可视化过程与草稿归档库 (Visualization Archive)

本目录归档建模研发与数据探索（EDA）期间生成的中间探索性图件、已融合的历史版本及其绘图脚本。

---

## 归档结构

* [`images/`](images/)：中间阶段图件（共 60 余张）。
  * 包含初期烘房一阶差分图、状态空间相轨迹图、FVM 三维五环线稿不同透视方案对比图，以及移动网格宏微观双尺度取景框微调对比图。
* [`scripts/`](scripts/)：对应历史绘图与数据处理脚本。
* [`pdf/`](pdf/)：部分历史矢量图中间件备份。

正式录用于论文的 10 张出版级主图与生产脚本统一维护于上一级目录 [`../`](../) 与 [`../scripts/`](../scripts/)。
