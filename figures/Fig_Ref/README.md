## 1. 核心图件结构与论文排版设计哲学

传统论文在展现圆柱药材内部场分布时，多采用离散时刻的二维剖面等值线或三维云图。此类表达割裂了“时间连续演进”与“空间径向梯度”的内在关联。本项目采用**“极坐标时钟披萨展开图（Clockwise Radial Pizza Plot）”**与**“阿基米德收缩螺旋披萨图（Archimedean Shrinkage Spiral Pizza Plot）”**，并在 **LaTeX A4 页面标准** 下实现了一体化 1×2 并列出版级排版。

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│                             q1 / q4 combined_pizza                               │
│  ┌─────────────────────────────────────┐    ┌─────────────────────────────────┐  │
│  │         【左图：含水率场演变】          │    │        【右图：温度场演变】       │  │
│  │  • 水分 Coolwarm 调色板             │    │  • 热力学 Inferno 调色板        │  │
│  │  • 标注 R0 = 2 cm、r (cm) 坐标轴     │    │  • 精简标尺：仅保留轴线与分度刻度 │  │
│  │  • 0.5、1.0、1.5 标尺平行倾斜 +45°   │    │  • 0.5、1.0、1.5 标尺平行倾斜 +45° │  │
│  │  • 独立高清晰度竖直色标条            │    │  • 独立高清晰度竖直色标条        │  │
│  └─────────────────────────────────────┘    └─────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────────┘
```

### 1.1 八大顶级学术期刊规范设计要点

1. **左右一体化 1×2 紧凑画幅（A4 版面极致优化）**：
   - 画布尺寸统一设定为 **$3200 \times 1380$**（长宽比 $\approx 2.32 : 1$）。
   - 在标准 A4 页面（正文版芯宽 `\textwidth \approx 160\,\mathrm{mm}$）中，插入后图幅高度仅占约 **$69\,\mathrm{mm}$**（约版面高度的 $1/4$），坚决杜绝了占用半页以上导致的排版换页空洞。
   - 两个主圆盘的物理印刷直径高达 **$58\,\mathrm{mm}$**，比原先单图正方形排版利用率提升超 $16\%$，空间利用率拉满。

2. **叙述逻辑协同：含水率先行，温度在后**：
   - 传统物理习惯常将温度置于左侧，但本题核心关注目标为药材脱水干燥动力学与最终达标含水率。
   - 将**含水率场置于左图**，**温度场置于右图**，完美呼应论文正文先论述水分蒸发扩散、再论述温度平衡的行文逻辑。

3. **差异化标尺去冗余（Asymmetric Annotation）**：
   - 双图共享相同的圆柱几何尺寸（初始半径 $R_0 = 2\,\mathrm{cm}$）。若在两张图上均标注 $R_0 = 2\text{ cm}$ 和 $r\ (\mathrm{cm})$ 轴名，会产生视觉疲劳。
   - **左图**：作为几何基准图，完整标注 $R_0 = 2\text{ cm}$ 与倾斜轴名 $r\ (\mathrm{cm})$；
   - **右图**：主动精简，删去 $R_0$ 和 $r$ 符号，仅保留坐标轴线及 $0.5, 1.0, 1.5$ 刻度数字，画面极其典雅素净。

4. **平行 $+45^\circ$ 标尺数字倾斜（彻底消除重叠）**：
   - 在 $-45^\circ$（10:30 方向）呼吸间隙通道中，原先横排的 `0.5` 刻度由于接近中心核区（通道收窄至仅 $\sim 42\,\mathrm{px}$），易压在深色扇区边界线上。
   - 新版将 `0.5`、`1.0`、`1.5` 数字统一**旋转 $+45^\circ$ 与标尺轴线完全平行**，定位在通道正中央，双侧留出 $>12\,\mathrm{px}$ 的充裕间距，彻底消除重叠。

5. **色标尺度数字超清放大（Enlarged High-Contrast Colorbars）**：
   - 色标条刻度数值（如温度 $36.8, 36.0, 34.0, \dots$ 与含水率 $2.55, 2.25, 2.00, \dots$）字号由 `28` 显著提升至 **`38`（Bold 700 粗体）**。
   - 刻度线延长至 `18 px`、线宽增至 `2.2 px`，在 A4 打印缩放下依然清晰锐利，无视力负担。

6. **去除底部冗余子图题，由正文统一引导**：
   - 彻底移除了原先内嵌在图内的 `(a) 温度分布演变` 与 `(b) 含水率分布演变` 文字，使画布下边距收紧，版面更平整。论文中直接通过图题（caption）统一指示“（左：含水率；右：温度）”。

7. **去摩尔纹混合光栅化（Moiré Elimination in Problem 4）**：
   - 问题四因半径连续变化，若采用密集多边形拼接在屏幕缩放时会产生严重摩尔纹（Moiré pattern）。
   - 脚本采用**二维笛卡尔场网格化双线性插值**，以无损透明 PNG 作为矢量图的嵌入底图（Base64 Data URI），辅以矢量标尺与轮廓线，兼具无伪影色彩过渡与晶莹剔透的矢量文字。

8. **问题四天然几何自明性（去除多余箭头）**：
   - 问题四阿基米德收缩螺旋外边界随时间推移由 $2.0\,\mathrm{cm}$ 逐步萎缩至 $1.41\,\mathrm{cm}$，其顺时针展开的几何形态本身已具有极强的时间流向指示性，因此主动去除了顶部的顺时针箭头，维持高雅留白。

## 2. 成果图科学内涵对照

### 2.1 问题一：预热平衡阶段（$0 \sim 1800\,\mathrm{s}$）

| 物理场 | 对应调色板 | 数值范围 | 物理机理与图件特征 |
|---|---|---|---|
| **含水率场（左）** | `coolwarm` | $1.50 \sim 2.55\,\mathrm{kg/kg}$ | 初始（$t=0\,\mathrm{s}$）全域均匀饱和纯红（$2.55$）；随着外界热风掠过，表层迅速失水转蓝（$1800\,\mathrm{s}$ 降至 $1.51$），但因内部湿分有效扩散系数较低（$D \sim 10^{-10}\,\mathrm{m^2/s}$），药材中心（$r < 1\,\mathrm{cm}$）长期保持深红未动，直观揭示**表面蒸发强烈而芯部质扩散迟滞（Mass Diffusion Lag）**特征。 |
| **温度场（右）** | `thermal` | $28.0 \sim 36.8^\circ\mathrm{C}$ | 初始为均匀室温深黑色（$28^\circ\mathrm{C}$）；外界 $50^\circ\mathrm{C}$ 热风对流换热迅速使表层升至亮黄色（$36.8^\circ\mathrm{C}$），热前沿快速向内渗透（芯部升至紫红色约 $33.6^\circ\mathrm{C}$）。热扩散深度显著大于水分扩散深度，揭示热-质传递的时间尺度失配。 |

### 2.2 问题四：动态收缩全流程（$0 \sim 51.1\,\mathrm{h}$）

| 物理场 | 对应调色板 | 数值范围 | 物理机理与图件特征 |
|---|---|---|---|
| **含水率场（左）** | `coolwarm` | $0.05 \sim 2.55\,\mathrm{kg/kg}$ | 真实反映药材全时域（$0 \to 51.1\,\mathrm{h}$）由鲜药材（$2.55$）烘干至干药材（$0.05$）的收缩过程。外边界线呈现阿基米德螺旋线特征，半径从 $2.0\,\mathrm{cm}$ 萎缩至 $1.41\,\mathrm{cm}$；由于干缩效应加剧了内部水分向外迁移阻力，后半程水分脱附梯度显著变缓。 |
| **温度场（右）** | `thermal` | $28.0 \sim 50.0^\circ\mathrm{C}$ | 药材在经历约 $3 \sim 4\,\mathrm{h}$ 的初期升温后，由于物料导热系数与对流换热系数相对干燥总时长极快，整根药材温度迅速逼近热风设定值（$50^\circ\mathrm{C}$，全域亮黄色）。时刻标签针对性地配置为 $0\mathrm{h}, 0.5\mathrm{h}, 1\mathrm{h}, 1.5\mathrm{h}, 2\mathrm{h}, 2.5\mathrm{h}, 15\mathrm{h}, 30\mathrm{h}, 51.1\mathrm{h}$，科学展现了热平衡过程。 |

## 4. 全流程重新复现指南

若需要重新生成或微调上述图件，请按照如下步骤操作：

### 4.1 生成 SVG 与渲染超清 PNG

在竞赛根目录下打开终端，执行以下命令：

```bash
cd figures/Fig_Ref

# 1. 运行问题一排版脚本（自动生成 q1_combined_pizza.svg 并调用无头 Chrome 2x 渲染 PNG）
python plot_q1_combined_pizza.py

# 2. 运行问题四排版脚本（自动生成 q4_combined_pizza.svg 并调用无头 Chrome 2x 渲染 PNG）
python plot_q4_combined_pizza.py
```

### 4.2 同步成果至主图件库 `figures/`

```bash
# 复制最新成品至上级主图件库进行归档冻结
powershell -Command "Copy-Item 'q1_combined_pizza.*','q4_combined_pizza.*' -Destination '..' -Force"
```
