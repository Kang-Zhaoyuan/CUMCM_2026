# 赛题文件与数据字典 (Problem & Experimental Data)

本目录归档 2026 年高教社杯全国大学生数学建模竞赛 A 题的官方命题文档与全部输入实验数据。

---

## 赛题文档
* [`A题.pdf`](A题.pdf)：官方赛题文件（包含题目背景、四问具体要求及参数附录）。
* [`problem_A_text.txt`](problem_A_text.txt)：赛题文本提取，用于快速检索物理参数与方程定义。
* [`A题_extracted.txt`](A题_extracted.txt)：赛题符号与数据结构提取。

---
